# SignupAlphaGrow WMS - plain HTML / CSS / JS

Open `index.html` in a browser (no build step, no server needed).

- `core.js`  business rules, validation and an in-memory database (port of lib.php and the page handlers)
- `app.js`   screens and events
- `style.css` your original stylesheet
- Demo logins: admin / manager / operator / viewer, password `Demo@12345!` (mock only). Data resets on refresh.
